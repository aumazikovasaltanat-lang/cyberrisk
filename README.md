# cyberriskexe

1. Drinkit стиліндегі ақылды кофе кассасы (Smart Coffee POS):
Бұл — кофехана жұмысын автоматтандыруға арналған ыңғайлы десктоптық қосымша. Бағдарлама арқылы клиент сусынның көлемін, сүт түрін және қосымша сироптарын өзі таңдап, бағасын бірден көре алады. Барлық тапсырыс баристаның жеке экранына нақты уақыт режимінде түсіп, дайындалу барысы таймермен бақыланады.

2. Фокус пен жұмысқа арналған Lo-Fi аудио-станция (Lo-Fi Focus Station):
Бұл — сабақ оқу немесе жұмыс істеу кезінде зейінді жинақтауға арналған дербес медиа-қосымша. Мұнда жаңбыр, от жалыны сияқты тыныштандыратын атмосфералық дыбыстарды қалаған көлемде бір-бірімен үйлестіріп қосуға болады. Бағдарламаның экранында дыбыспен бірге ырғалатын эквалайзер мен уақытты бақылайтын кіріктірілген фокус-таймер бар.
